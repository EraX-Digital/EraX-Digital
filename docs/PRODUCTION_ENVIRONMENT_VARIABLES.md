# Production environment variables

`.env.example` lists every variable. Placeholder values are not secrets. `.env` stays uncommitted.

The API reads server variables through `loadEnv()` in `@erax/config`. An invalid production configuration throws `Invalid environment` and the process does not listen. The browser bundle can see only variables prefixed with `NEXT_PUBLIC_`. The only such variable is `NEXT_PUBLIC_API_URL`.

## Frontend public variables

Read by Next.js at build time and inlined into the browser. Set them on the Vercel projects, not in the API host.

| Variable | Production value | Local value |
| --- | --- | --- |
| `NEXT_PUBLIC_API_URL` | `https://api.erax.digital` | `http://127.0.0.1:4000` in `apps/web/.env.development` and `apps/admin/.env.development` |

A Vercel preview build must use the preview API URL. `publicApiUrl()` rejects a missing, non-HTTPS, or localhost value when `VERCEL_ENV` is `production` or `preview`.

## Backend-only secrets

These must never use the `NEXT_PUBLIC_` prefix.

| Variable | Purpose |
| --- | --- |
| `SESSION_COOKIE_SECRET` | At least 32 characters. Values containing `replace-with` are rejected. |
| `SMTP_USER` | SMTP username, when the provider requires one. |
| `SMTP_PASSWORD` | SMTP password. |
| `S3_ACCESS_KEY_ID` | Object-storage access key. Required when `MEDIA_DRIVER=s3`. |
| `S3_SECRET_ACCESS_KEY` | Object-storage secret key. Required when `MEDIA_DRIVER=s3`. |
| `DEV_ADMIN_EMAIL` | Development seed only. |
| `DEV_ADMIN_PASSWORD` | Development seed only. At least 12 characters. Not a production account. |

`ERAX_APPROVE_REMOTE_MIGRATE` is not in `.env.example` as an enabled flag. Set it to `1` in the shell for one approved `pnpm db:migrate` or `pnpm db:verify` against a non-local host.

## Database variables

| Variable | Production | Local |
| --- | --- | --- |
| `DATABASE_DRIVER` | `postgres` | `postgres`, or `pglite` with `--lite` |
| `DATABASE_URL` | Neon pooled URL, `sslmode=require` | `postgres://erax:erax_local_dev_only@127.0.0.1:5432/erax` |
| `DATABASE_MIGRATION_URL` | Neon direct URL | Empty. Migrations then use `DATABASE_URL`. |
| `DATABASE_POOL_MAX` | `10` for one API process | `10` |
| `DATABASE_SSL` | `require` | `disable` for Docker Compose without TLS |
| `PGLITE_DIR` | Ignored, because PGlite is rejected | `./var/pglite` |
| `ERAX_AUTO_MIGRATE` | Unset or `false` | `true` |

Production rejects PGlite, a URL containing `localhost`, `127.0.0.1`, or `erax_local_dev_only`, and `DATABASE_SSL=disable`.

## Email provider variables

| Variable | Production | Local |
| --- | --- | --- |
| `EMAIL_MODE` | `smtp` | `outbox` |
| `EMAIL_OUTBOX_DIR` | Unused | `./var/outbox` |
| `SMTP_HOST` | Provider host | `127.0.0.1` (Mailpit) |
| `SMTP_PORT` | Provider port, often `587` | `1025` |
| `SMTP_FROM` | `EraX <no-reply@erax.digital>` | `EraX <no-reply@localhost>` |
| `SMTP_USER` | Provider user, if required | Empty |
| `SMTP_PASSWORD` | Provider password, if required | Empty |

Production rejects the outbox and a localhost SMTP host or from-address. The SMTP code path has not delivered a message to a real provider. Do not treat email as working until the checklist's delivery test passes.

## Media storage variables

| Variable | Production | Local |
| --- | --- | --- |
| `MEDIA_DRIVER` | `s3` | `filesystem` |
| `MEDIA_ROOT` | Unused | `./var/media` |
| `S3_ENDPOINT` | S3-compatible endpoint, including AWS or Cloudflare R2 | Empty |
| `S3_REGION` | Region, or `auto` for some compatible providers | Empty |
| `S3_BUCKET` | Private bucket name | Empty |
| `S3_ACCESS_KEY_ID` | Access key | Empty |
| `S3_SECRET_ACCESS_KEY` | Secret key | Empty |
| `S3_FORCE_PATH_STYLE` | `true` when the provider requires path-style URLs | `false` |

Production rejects `filesystem`. Uploaded objects use the key prefixes `avatars/`, `covers/`, `posts/`, and `communities/`. The S3 adapter was tested with an in-memory client. It was not tested against a live bucket.

## Cache variables

| Variable | Production | Local |
| --- | --- | --- |
| `RATE_LIMIT_STORE` | `valkey` | `valkey`, or `memory` with `--lite` |
| `VALKEY_URL` | A remote `rediss://` URL | `redis://127.0.0.1:6379` |

Production rejects the in-process store and a localhost Valkey URL. The API uses `ioredis` and the Redis protocol. A Valkey, Redis, or Redis-compatible service can supply that URL. None of those services was connected in this session. Readiness reports Valkey as not connected when the memory store is selected.

## Authentication variables

| Variable | Production | Local |
| --- | --- | --- |
| `WEB_ORIGIN` | `https://app.erax.digital` | `http://127.0.0.1:3000` |
| `ADMIN_ORIGIN` | `https://admin.erax.digital` | `http://127.0.0.1:3001` |
| `API_PUBLIC_ORIGIN` | `https://api.erax.digital` | `http://127.0.0.1:4000` |
| `SESSION_COOKIE_SECRET` | Generated secret | Generated by `node scripts/write-dev-env.mjs` |
| `SESSION_TTL_SECONDS` | `604800` | `604800` |
| `COOKIE_SECURE` | `true` | `false` |
| `COOKIE_DOMAIN` | `.erax.digital` | Empty |

The session cookie is host-only on the API. The CSRF cookie uses `COOKIE_DOMAIN` so JavaScript on `app.erax.digital` and `admin.erax.digital` can read it and send `x-erax-csrf`. Both cookies are `SameSite=Lax`. The two application hosts share the registrable domain `erax.digital`, so the browser treats the API calls as same-site.

Production requires HTTPS origins. When the web host and the API host differ, `COOKIE_DOMAIN` is required and must be a parent of the web, admin, and API hosts.

## Process and proxy

| Variable | Production | Local |
| --- | --- | --- |
| `NODE_ENV` | `production` | `development` |
| `API_HOST` | `0.0.0.0` on the API host | `127.0.0.1` |
| `API_PORT` | The port the process listens on, often `4000` | `4000` |
| `INDEXER_HOST` | `0.0.0.0` or `127.0.0.1` if it shares the machine | `127.0.0.1` |
| `INDEXER_PORT` | `4001` unless the host map says otherwise | `4001` |
| `TRUST_PROXY` | `true` only behind a proxy that overwrites `X-Forwarded-For` | `false` |
| `ENABLE_API_DOCS` | `false` | `true` |

The indexer reads `INDEXER_HOST` and `INDEXER_PORT` only. Do not give that process the database URL or the signing secret.

## Blockchain placeholders

These names are in `.env.example` and are not read by the API or the indexer:

- `EVM_CHAIN_ID`
- `EVM_RPC_URL`
- `SOLANA_CLUSTER`
- `SOLANA_RPC_URL`

The indexer reports that no chain is connected. Leave the values empty.
