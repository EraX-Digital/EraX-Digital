# EraX Digital — Reference Repository Audit

Audit date: 2026-11-03

Method: GitHub REST API for default branch, license SPDX field, description, language, archived flag, and the latest commit on the default branch; raw manifests (`package.json`, `Cargo.toml`, `Anchor.toml`, `README`, `LICENSE`) for the repositories whose license or layout affects an integration decision. Directory listings were retrieved for repository roots before the API returned 403. Test suites inside those repositories were not executed. This is a source and license inspection, not a security audit of third-party code, and it is not a legal opinion.

Where the assignment linked a GitHub organization or a meta-repository, the concrete repositories that hold the relevant source were inspected and are called out below. `coral-xyz/anchor` and `solana-foundation/anchor` resolved to the same commit and are treated as one project, with `solana-foundation/anchor` as the canonical remote.

`pushed_at` on a repository can move because of non-default branches. The commit hash and commit date below are the default-branch HEAD returned by the commits API.

Organization URLs from the assignment map as follows.

- `github.com/farcasterxyz` is an organization. The repositories that matter for this decision are `protocol`, `contracts`, `hub-monorepo`, and `snapchain`.
- `github.com/lens-protocol` is an organization. `lens-v3` is the current contract tree and is the repository inspected. Older Lens repositories were not required once `lens-v3` showed a GPL-3.0-only license and a zkSync-specific design.

## Abandoned, frozen, or incomplete areas

- TribeEco still links `tribe-indexer` and `tribe-cast-server`, and its own README marks both deprecated and merged into `tribe-hub`.
- TribeEco is a submodule shell. A clone without submodules does not contain the protocol.
- `hey.xyz` is a frozen public snapshot. The HEAD commit inspected here only updates the README. The README says production changes after 2026-05-15 are not in the repository.
- `lens-v3` last inspected commit (2026-03-06) updates license text. The tree is GPL-3.0-only, targets zkSync, and depends on OpenZeppelin 4.9.
- `farcasterxyz/protocol` is marked `unlicensed` in `package.json`.
- RainbowKit’s default branch has not moved onto wagmi 3. AppKit has. EraX follows RainbowKit’s peer range because AppKit’s license is excluded.
- Quicknode’s Anchor 2 examples target `anchor-cli 2.0.0-rc.2`, which is a release candidate.

## Dependency notes that affect EraX

- Hey’s client uses wagmi 2 and viem 2. That pairing matches RainbowKit’s peer range. It does not justify importing Hey.
- Tribe’s SDK pins Anchor 0.31.1 and `@solana/web3.js` 1.x. EraX will use the stable Anchor 0.31 line and the wallet-adapter stack, which still sits on `@solana/web3.js` 1.x. `@solana/kit` is not a drop-in replacement for the adapter and is not adopted in the first wallet release.
- Lens V3’s OpenZeppelin 4.9 dependency is not the version EraX will use.
- Farcaster contracts show a Foundry layout worth mirroring (`src`, `test`, `script`, `foundry.toml`). The contracts themselves stay upstream.

## Integration decisions

Use as libraries or toolchains, pinned and locked:

- OpenZeppelin Contracts, MIT, as a Foundry dependency.
- Foundry, Apache-2.0, as an installed toolchain.
- Anchor, Apache-2.0, as an installed toolchain.
- RainbowKit, wagmi, and viem, MIT, for Ethereum and Base connection.
- Solana Wallet Adapter, Apache-2.0, for Solana connection.
- SIWE, Apache-2.0, and the SIWS message format, MIT, for wallet login. Verification runs on the server.

Use as architecture references and reimplement:

- TribeEco, for the split between on-chain identity and off-chain content.
- Hey and Lens, for feed, profile, and creator-product concepts.
- Farcaster contracts and hubs, for registry and indexer boundaries.
- Solana Foundation program examples, for how Anchor tests should be structured.

Exclude from the EraX source tree:

- `hey.xyz` (GPL-3.0 file, AGPL-3.0 claim).
- `lens-v3` (GPL-3.0-only).
- `farcasterxyz/snapchain` (GPL-3.0).
- `farcasterxyz/protocol` text (`unlicensed`).
- `reown-com/appkit` (community license with network and commercial thresholds).
- Quicknode finance examples (out of scope, and no `LICENSE` file was found).
- Tribe source (MIT/ISC statements conflict and `LICENSE` files were not present).

No reference repository is described here as EraX-original code.
